# Transparency Dental Clinics — redesign demo

Premium RTL-first website demo for [Transparency Dental Clinics](https://www.tclinics.net/) in Jeddah.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Toggle **العربية | EN** in the header.

Factual clinic information (address, phone, CEO, testimonial, positioning) is taken from the live site and official channels. Google rating is stored in `src/lib/site.ts` so it can be updated. The booking flow is a visual demo and is not connected to the clinic’s scheduling system.
